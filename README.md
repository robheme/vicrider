VicRider - study tool for Motorcycle Learner Knowledge test in Victoria, Australia.

Created with Gemini.

Offers:
- 150 built-in questions taken from the VicRoads Rider Handbook as well as general road rules in Victoria.
- User can determine the amount of questions asked
- Filter questions based on the Rider Handbook, road rules, or a combination of both
- Focus on questions not previously seen yet, or pure random selection.
- Option to refresh the question bank with new questions. This will require a Google Gemini API key which only gets stored in your browser.
- Score and review, with detailed answers.
